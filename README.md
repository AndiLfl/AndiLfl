## 🧑‍💻 About Me

- 🔭 I build full-stack web apps with **Laravel**, **Livewire** and **Vue**
- 🎨 I care about clean, fast UIs — **Tailwind CSS v4** is my daily driver
- 🤖 I supercharge my workflow with **AI**: zAI, Codex and Claude
- 📡 I love **IoT** — connecting devices, sensors and the real world to the web
- 🐳 Everything runs in **Docker**, backed by **Postgres** & **Redis**, on **Linux**
